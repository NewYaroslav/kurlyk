Detailed Description

RAII lease that owns temporary serialized rate-limit locks.

This object is intended to be stored through HttpRateLimitLeasePtr. A request context can keep one lease while it owns serialized rate-limit resources, such as general/specific rate limits or cooldown keys.

When the last shared lease is destroyed, the lease invokes the stored release callback and releases all serialized resources owned by this request context.

Note
The lease object itself is non-copyable. Copy HttpRateLimitLeasePtr instead.
